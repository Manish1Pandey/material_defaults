# material_defaults example

A gallery of every member of `MaterialDefaults` (expand a component to see all
of its properties, with state-dependent values resolved for enabled, hovered,
pressed, selected and disabled), switchable between seed colors and
light/dark, plus `DefaultsPillButton`: a button implemented from scratch that
looks and reacts like `FilledButton` by resolving
`MaterialDefaults.of(context).filledButton` itself.

```sh
flutter run -d chrome   # or macos / an Android or iOS device
```
